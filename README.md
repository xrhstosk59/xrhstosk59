## 🚀 Projects

### Travel Planner — AI-Powered Travel Platform

_Diploma thesis, team of 2. Private repository, available on request._

Full-stack travel platform where users earn points for approved local contributions and spend them on Gemini-generated day-by-day itineraries.

**Next.js 16 · TypeScript · Supabase (PostgreSQL) · Google Gemini · Upstash Redis · Mapbox**

- Points-based contribution system with an approval workflow
- Personalized recommendations and Greek/English localization (next-intl)
- Row Level Security, CSRF protection, and rate limiting
- Tested with Vitest and Playwright. Deployed on Vercel with Sentry monitoring

### [SQLatch](https://github.com/xrhstosk59/SQLatch) — Visual SQL Learning Platform

Browser-based platform for learning SQL through drag-and-drop blocks. Started as a university project; the current version includes my later work on maintenance, features, UI/UX, and documentation, with selective AI-assisted tooling.

**Next.js 15 · React 18 · TypeScript · Blockly · SQLite WASM**

- 18 Blockly block types generating SELECT, JOIN, aggregation, and DDL/DML queries
- Runs entirely in the browser via SQLite WASM — no backend, no installation
- 11 lessons, 7 worksheets, and 2 story-based scenarios written in Markdown
- Query history, auto-saving workspaces, shareable URLs, interactive schema diagrams, CSV/JSON export
